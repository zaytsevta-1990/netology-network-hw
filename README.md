# Netology Network Homework

Домашняя работа по теме клиент-серверного взаимодействия.

## Что сделано
- `Server` и `Client` для обязательной задачи
- `FancyServer` и `FancyClient` для задачи со звездочкой

## Важное для звездочки
Для `FancyClient` нужно добавить в файл `hosts` строку:

```text
127.0.0.1 netology.homework
```

## Запуск
Сначала запускается сервер, потом клиент.

### Обязательная задача
```bash
java ru.netology.network.Server
java ru.netology.network.Client
```

### Задача со звездочкой
```bash
java ru.netology.network.FancyServer
java ru.netology.network.FancyClient
```
